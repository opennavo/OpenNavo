- El menú de una actualización puede desinstalar esa app. Antes de quitar nada, sigues revisando la desinstalación.

## Correcciones

- Si Hermes se reinicia mientras carga su catálogo de modelos, OpenNavo lo intenta de nuevo. Si el catálogo sigue sin cargarse, indica que Hermes se está reiniciando en lugar de mostrar un código de conexión.
