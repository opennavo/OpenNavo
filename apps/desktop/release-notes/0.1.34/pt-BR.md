## Novidades

- O menu de uma atualização pode desinstalar esse app. Você ainda revisa a desinstalação antes de qualquer remoção.

## Correções

- Se o Hermes reiniciar enquanto o catálogo de modelos está carregando, o OpenNavo tenta de novo. Se o catálogo ainda não carregar, ele informa que o Hermes está reiniciando em vez de mostrar um código de conexão.
