## Novità

- Il menu di un aggiornamento può disinstallare quell’app. Prima di rimuovere qualcosa, controlli ancora la disinstallazione.

## Correzioni

- Se Hermes si riavvia mentre carica il catalogo dei modelli, OpenNavo riprova. Se il catalogo non si carica ancora, indica che Hermes si sta riavviando invece di mostrare un codice di connessione.
