## Nouveautés

- Le menu d’une mise à jour peut désinstaller cette app. Vous vérifiez toujours la désinstallation avant toute suppression.

## Corrections

- Si Hermes redémarre pendant le chargement de son catalogue de modèles, OpenNavo réessaie. Si le catalogue ne se charge toujours pas, l’app indique que Hermes redémarre au lieu d’afficher un code de connexion.
