## 新功能

- 本地 MCP：在設定中開啟後，可一鍵複製配置到你的 AI 應用。AI 應用可以查詢應用，並且只有在你於 OpenNavo 確認視窗中點選「允許」後，才能安裝應用或將應用移到垃圾桶。每個請求都會記錄在本地操作記錄中。

## 改進

- 應用詳情頁改版，新增「基本資訊」卡片，展示來源、價格、系統要求和 GitHub Star。被 Homebrew 停用的應用會顯示提示，不再提供安裝命令。
- 「其他名稱」只顯示與你的語言相符的名稱。
- 網頁連結發起的安裝和防火牆聯網提醒改用 OpenNavo 自己的視窗。「拒絕」或「阻止」在左側，「允許」要稍等片刻才能點選，按鍵也無法放行。關閉安裝確認視窗或切換到別處（包括 AI 應用發起的確認）都算拒絕。合集連結會列出全部應用，並說明跳過的應用及原因。
- 已從公開目錄下架的已安裝應用仍可開啟和管理。
