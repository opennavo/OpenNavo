## Miglioramenti

- L’elenco delle conversazioni e il campo di testo mostrano quando un’altra chat di Hermes sta rispondendo o attende la tua risposta. I messaggi in coda partono nell’ordine in cui li hai scritti.

## Correzioni

- Cambiare chat o profilo non interrompe più una risposta di Hermes e non scarta un messaggio che era già in attesa.
- La diagnostica di Hermes segue la connessione e il profilo aperti. Una connessione Panel non mostra più l’Hermes locale di questo Mac.
- Interrompere una risposta la segna come interrotta, non come risposta completata. Se un messaggio con file non può ancora essere inviato, il testo e i file scelti restano nel campo.
- Il download del cask Homebrew include la versione dell’app e richiede macOS Ventura.
