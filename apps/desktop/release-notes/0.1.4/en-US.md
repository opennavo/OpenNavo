## App updates

- Added automatic update checks after launch, limited to one successful check per day. You can turn this off in Settings.
- Added an update dialog with release notes, download progress, installation retries, and a restart action that waits for active tasks to finish.
- Manual checks in Settings now use the same update dialog.

## Improvements

- Refined the Discover layout and collection artwork for easier browsing.
- Homebrew setup now uses the official source on computers whose system language is not Chinese; Chinese-language systems retain mirror selection.
