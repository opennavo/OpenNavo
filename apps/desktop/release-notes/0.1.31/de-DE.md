## Neu

- Entdecken erhält eine Entwicklerkarte, die zeigt, woher Apps kommen. Sie können eine App einreichen oder eine von Ihnen betreute App beanspruchen und aktualisieren. Das Formular öffnet sich im Browser. Die Entwicklerauswahl erscheint unter Entdecken.
- Hermes kann getrennte Profile behalten. Jedes Profil hat ein eigenes Modell, eigenes Gedächtnis, eigene Fähigkeiten und Sitzungen. Ein Profil kann sich mit einem Hermes-Panel auf diesem Mac oder über Tailscale verbinden.
- Wenn Hermes eine Entscheidung braucht, können Sie ein Werkzeug freigeben, eine Frage beantworten oder ein Geheimnis angeben. Diese Karten können gleichzeitig offen bleiben.
- Der Panel-Verlauf listet aktuelle, geplante und archivierte Sitzungen. Sie können jedes Profil auf diesem Mac einbeziehen.

## Verbesserungen

- Das Einschalten der Mac-Steuerung gewährt volle Kontrolle und fragt nicht vor jedem Schreibvorgang. Einzelne Fähigkeiten lassen sich in den Hermes-Einstellungen weiter abschalten.
- Die Hermes-Unterhaltung bleibt bei der neuesten Nachricht, und der Abschnitt zum Nachdenken ist beschriftet.
- Die lokale Hermes-Laufzeit wird vor dem Start geprüft.
- Ein Hermes-Profilfenster bleibt bei diesem Profil und übernimmt nicht die Zugangsdaten eines anderen.
- Die Bildlaufleisten des Assistenten bleiben schmal, eine lange Antwort verschiebt den Text also nicht mehr.

## Korrekturen

- Symbole im Entwicklerformular verdecken den eingegebenen Text nicht mehr.
