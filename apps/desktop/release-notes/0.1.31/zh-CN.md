## 新功能

- 发现页新增开发者地图，标出应用来自哪里。你可以提交应用，或认领并更新自己维护的应用。完整表单在浏览器中打开。发现页会显示开发者精选。
- Hermes 可以分开保存多个 Profile。每个 Profile 有自己的模型、记忆、技能和会话，也可以连接这台 Mac 上的 Hermes Panel，或通过 Tailscale 连接。
- Hermes 需要你决定时，可以批准工具、回答问题，或提供一项秘密。这些卡片可以同时开着。
- Panel 历史列出最近、已排程和已归档的会话，也可以把这台 Mac 上的每个 Profile 都包括进来。

## 改进

- 打开 Mac 控制时会授予完全控制，并且不会在每次写入前询问。各项能力仍可在 Hermes 设置里单独关闭。
- Hermes 对话会停在最新一条消息上，推理部分也有了标题。
- 本地 Hermes 运行环境会在启动前核对。
- 每个 Hermes Profile 窗口只留在该 Profile 里，不会带上另一个 Profile 的凭据。
- 助手里的滚动条更窄，长回复不再把文字挤偏。

## 修复

- 开发者表单里的图标不再挡住正在输入的文字。
