## 新機能

- 見つけるに開発者マップを追加し、アプリがどこから来たかを示します。アプリを投稿したり、自分が保守するアプリを申請して更新したりできます。フォームはブラウザで開きます。見つけるには開発者ピックも表示されます。
- Hermes は Profile を分けて保持できます。各 Profile には独自のモデル、メモリ、スキル、セッションがあります。この Mac 上の Hermes Panel にも、Tailscale 経由でも接続できます。
- Hermes が判断を求めるとき、ツールの承認、質問への回答、秘密の入力ができます。これらのカードは同時に開いたままにできます。
- Panel の履歴には、最近、スケジュール済み、アーカイブ済みのセッションが並びます。この Mac 上のすべての Profile を含めることもできます。

## 改善

- Mac 制御をオンにすると完全な制御が許可され、書き込みのたびに確認しません。個々の機能は Hermes の設定でオフにできます。
- Hermes の会話は最新のメッセージに留まり、推論の部分には見出しが付きます。
- ローカルの Hermes 実行環境は、起動前に照合されます。
- Hermes の Profile ウィンドウはその Profile に留まり、別の Profile の資格情報を引き継ぎません。
- アシスタントのスクロールバーは細くなり、長い返信で本文がずれません。
