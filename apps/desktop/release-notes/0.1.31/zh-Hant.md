## 新功能

- 發現頁新增開發者地圖，標出應用來自哪裡。你可以提交應用，或認領並更新自己維護的應用。完整表單在瀏覽器中開啟。發現頁會顯示開發者精選。
- Hermes 可以分開儲存多個 Profile。每個 Profile 有自己的模型、記憶、技能和會話，也可以連線這台 Mac 上的 Hermes Panel，或透過 Tailscale 連線。
- Hermes 需要你決定時，可以批准工具、回答問題，或提供一項秘密。這些卡片可以同時開著。
- Panel 歷史列出最近、已排程和已歸檔的會話，也可以把這台 Mac 上的每個 Profile 都包括進來。

## 改進

- 開啟 Mac 控制時會授予完全控制，並且不會在每次寫入前詢問。各項能力仍可在 Hermes 設定裡單獨關閉。
- Hermes 對話會停在最新一條訊息上，推理部分也有了標題。
- 本地 Hermes 執行環境會在啟動前核對。
- 每個 Hermes Profile 視窗只留在該 Profile 裡，不會帶上另一個 Profile 的憑據。
- 助手裡的捲軸更窄，長回覆不再把文字擠偏。

## 修復

- 開發者表單裡的圖示不再擋住正在輸入的文字。
